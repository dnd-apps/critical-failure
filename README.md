# critical-failure

Hosted on Cloudflare Pages: [critical-failure-zjn.pages.dev](https://critical-failure-zjn.pages.dev/)

## Requirements

- Node.js 20+
- [pnpm](https://pnpm.io/) (this repo is pnpm-only — `packageManager` is pinned in `package.json`)

## Project setup

```sh
pnpm install
```

### Compiles and hot-reloads for development

```sh
pnpm dev
```

### Compiles and minifies for production

```sh
pnpm build
```

Output lands in `dist/`. Preview it with `pnpm preview`.

### Lints and formats files

```sh
pnpm lint
pnpm format
```

## Stack

Vite 8 + React 19 + TypeScript + Tailwind CSS v4 + [shadcn/ui](https://ui.shadcn.com)
(radix-nova style, Radix primitives, Lucide icons).

UI primitives live in `src/components/ui/` and are generated by the shadcn CLI —
edit them freely, they are project code. To add more:

```sh
pnpm dlx shadcn@latest add <component>
```

`components.json` holds the CLI config; the `@/*` import alias maps to `src/`.

## Deploy

Deploys go to the `critical-failure` Cloudflare Pages project. Locally:

```sh
pnpm deploy
```

That builds and runs `wrangler pages deploy dist`; it needs a Cloudflare login
(`pnpm exec wrangler login`) or `CLOUDFLARE_API_TOKEN` in the environment.
`public/_redirects` provides the SPA fallback so deep links serve `index.html`.

## CI/CD

CI runs on [paws](https://github.com/mbround18/paws): `paws ci --toolchain node` on pull
requests, `paws semver --push` plus `paws changelog --commit` on `main`, and a Cloudflare
Pages deploy on published releases (needs the `CLOUDFLARE_API_TOKEN` and
`CLOUDFLARE_ACCOUNT_ID` secrets).
